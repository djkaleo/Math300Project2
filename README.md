# Math300Project2
This is a repository for Derek and Dylans collaborative project for Math 300 at WSU
We chose to explore two ODE systems that do not have closed form systems, specifically the Lotka-Votlterra system and the Lorenz system
Included in our Project 2 Jupyter notebook is code we used to estimate solutions and plot behavior. We primarily used scipys solve_ivp for this and basic plotting functions to plot the behavior. 

To run the notebook, simply download the notebook and run the entire thing from top to bottom
